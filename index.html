blackwell-isa

Machine-readable SASS ISA databases and generated references for NVIDIA Blackwell GPUs.

  • SM120 ISA Reference — consumer Blackwell (RTX 5090, GB202) — sm120.json
  • SM103a ISA Reference — datacenter Blackwell (B300 SXM6) — sm103a.json
  • SM121a ISA Reference — Grace-Blackwell (DGX Spark, GB10, unified memory) — sm121a.json
